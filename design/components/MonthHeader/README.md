# MonthHeader

The top of the Budget page. Provide the month, whether it is open or closed, and the four month figures.

- The month name is the page title in `text-display`, between previous and next buttons.
- An Open or Closed Pill follows the title. A closed month hides Add transaction and shows "Reopen" in place of "Close month".
- Stats in order: Income, Budgeted, Spent so far, Rest so far.
